## Changes
1. **Run-ID abort** (internal/agent/router.go)
   - `AbortRun` now requires `run.TenantID == ctx tenant` on every call, not only when a session key is given.
   - A run in another tenant returns NotFound.
   - The admin `chat.abort {runId}` path and the related-run retry in chat.go are both covered.
2. **Scheduler** (internal/scheduler/scheduler.go)
   - Queues are keyed by `sessionQueueKey{tenantID, sessionKey}`, with the tenant taken from the scheduling ctx.
   - `CancelSession` and `CancelOneSession` now take a ctx.
   - Callers:
     - `/stop` and `/stopall` (cancelVisibleChatRuns) pass the ctx through. `handleStopCommand` now falls back to `MasterTenantID` the same way `processNormalMessage` does, so single-tenant behaviour holds.
     - Team-task cancel: `TaskRunSessions` now stores `taskRunSession{tenantID, sessionKey}` (cmd/gateway_consumer_deps.go).
3. **Activity** (internal/agent/router.go)
   - Activity is keyed by `sessionRunKey`, using the run's tenant.
   - `UpdateActivity(runID, ...)` and `ClearActivity(runID)` resolve the key from the active run. `GetActivity(ctx, sessionKey)` reads with the caller's tenant.
   - Callers updated: cmd/gateway_events.go, cmd/gateway_consumer_normal.go, internal/gateway/methods/chat.go, internal/http/chat_concurrency_runtime.go.
