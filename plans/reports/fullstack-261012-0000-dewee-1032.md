## Changes
1. **Heartbeat busy check** (`internal/scheduler/scheduler.go`, `internal/heartbeat/{interfaces,ticker,mock_test}.go`)
   - `HasActiveSessionsForAgent(ctx, agentKey)` now counts only the session queues of the ctx tenant.
   - The heartbeat interface carries the ctx. The ticker already scopes it to the agent's tenant, with nil mapped to master.
2. **Throttle token estimate** (`internal/scheduler/queue.go`, `cmd/gateway_heartbeat.go`)
   - `TokenEstimateFunc(ctx, sessionKey)` replaces the old signature.
   - `SessionQueue.tenantID` is set from the scheduler key and passed to the callback in the ctx.
   - The cmd closure reads session history, prompt tokens and the context window with that ctx.
   - Before: the closure used `context.Background()`, so it read the master tenant's session with the same key.
3. **`ClearActivity`** (`internal/agent/router.go`)
   - It deletes the entry only while that entry's RunID is the finishing run (`Load` + `CompareAndDelete`), the same as `UnregisterRun`.

Single-tenant behaviour is unchanged: every production `Schedule` caller sets a non-nil tenant (master fallback), and a nil tenant still maps to the master session cache key.
